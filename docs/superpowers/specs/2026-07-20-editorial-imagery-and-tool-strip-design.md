# Shawnnova 网站影像与工具带设计说明

**日期：** 2026-07-20  
**状态：** 待用户复核  
**范围：** 首页主视觉、工作区三张项目图片、常用工具 Logo 带

## 1. 目标

把当前偏抽象、难以理解的金属与玻璃图替换为真实、有温度的创作现场，让访问者第一眼就能理解 Shawnnova 是一位把运营、销售、产品开发与 Vibe Coding 结合起来的独立开发者。

页面仍保持现有的冷静编辑感、留白和钴蓝强调色，不改造成常见的“科技公司模板页”。新增的工具 Logo 只作为工作方式的旁证，不抢人物、项目与联系方式的主叙事。

## 2. 核心视觉方向

采用“真实创作纪实 + 产品界面细节”的组合：自然光或柔和工作灯、可信的桌面环境、现代但不过度豪华的设备、克制的灰白与暖白色调，并以少量钴蓝物件呼应网站主题色。

图片不出现赛博朋克霓虹、漂浮界面、夸张机械结构、抽象雕塑、无法辨认的屏幕文字或明显的 AI 生成痕迹。人物只以背影、侧后方或局部入镜，避免生成一个清晰的虚构正脸来冒充本人。

所有品牌 Logo 都由网页中的准确矢量图标单独渲染，不让生成模型把 Logo 画进照片。图片中的屏幕内容保持低细节、不可读或使用中性界面模块，避免乱码与错误商标。

## 3. 四张图片

### 3.1 首页主视觉

- 场景：一位独立创作者从侧后方坐在安静工作室中，正在把想法变成可运行的数字产品。
- 画面信息：笔记本或显示器、纸质草图、少量便利贴、自然的手部动作；人物不露清晰正脸。
- 构图：主体偏右，预留左侧呼吸空间以配合首页文字；兼容桌面端 4:5 与移动端 4:3 裁切。
- 情绪：专注、稳健、长期主义，呼应“功不唐捐，玉汝于成”。

### 3.2 AI 视频工具

- 场景：手正在操作一套视频创作工作流，屏幕体现时间线、字幕轨道、片段和画面修复等结构。
- 画面信息：重点是“正在做产品”，而不是炫技；界面不出现可读品牌名或乱码。
- 构图：横向、近景，手与屏幕形成明确动作关系，适合工作区的大卡片。

### 3.3 桌面端体验

- 场景：整洁但有人使用痕迹的桌面，电脑中是克制的桌面应用界面，旁边有产品流程草图。
- 画面信息：同时表达产品设计、开发与可用性思考；避免摆拍式豪华设备陈列。
- 构图：横向、中近景，设备和纸面信息形成层次，移动端裁切后仍保留主要内容。

### 3.4 持续实验

- 场景：多个小型原型在被比较与试验，例如手机、平板、小屏幕、纸卡和手写假设。
- 画面信息：表达快速验证、运营反馈和持续迭代，不与“桌面端体验”重复。
- 构图：略俯视的横向工作台，重点分布在画面中部，便于响应式裁切。

## 4. 常用工具 Logo 带

在个人介绍与工作案例之间加入一条低调的“常用工具”带，首批包括：

- Codex
- 飞书
- GitHub
- VS Code
- Cloudflare
- Vercel

Logo 使用真实矢量路径或可靠的品牌图标包，并保留文字名称，便于开发小白和非技术访客识别。默认以单色、低对比度显示，悬停或键盘聚焦时使用钴蓝强调；深色和浅色主题都必须清晰可见。

工具带不是可点击的广告墙，默认不链接到第三方官网，也不暗示品牌合作或认证。图标附带可访问名称，动效遵循系统的“减少动态效果”设置。

## 5. 文案与可访问性

- 更新四张图片的替代文本，描述图片传达的工作场景，不堆砌关键词。
- 工具 Logo 同时显示文字标签，不依赖颜色或图形单独传达含义。
- 装饰性细节对辅助技术隐藏，重要内容保持正常阅读顺序。
- 不在图片中嵌入姓名、格言、联系方式或项目文案，避免小屏幕不可读。

## 6. 技术与性能约束

- 四张图各自独立，不复用同一张图片充当多个项目。
- 最终图片转换为高质量 WebP，并按实际显示尺寸控制文件体积；保留原始生成文件在工作过程目录，不把超大原图直接送到生产环境。
- 使用新的版本化文件名，更新内容配置中的路径与替代文本，避免浏览器/CDN 缓存继续显示旧图。
- 保持 Next.js 图片优化、既有响应式尺寸和页面布局；只有在必要时微调 `object-position`，不通过大幅放大来掩盖构图问题。
- Logo 图标应在本地构建产物中提供，避免依赖会被中国大陆网络拦截或变慢的第三方图标 CDN。

## 7. 验收标准

1. 首页与三个工作案例分别使用四张不同、具象、可理解的图片。
2. 图片中没有清晰虚构正脸、错误 Logo、乱码、水印和抽象金属雕塑。
3. Codex、飞书、GitHub、VS Code、Cloudflare、Vercel 六个工具名称与图标准确显示。
4. 工具带在手机和桌面上不溢出，在浅色与深色主题下都有足够对比度。
5. 页面原有中文/英文排版、联系方式表单与主题切换不受影响。
6. 通过单元测试、生产构建和浏览器端响应式检查。
7. 部署到 `260604.xyz` 后，使用用户已登录的 Chrome 验证真实线上页面与图片加载。

## 8. 不在本次范围内

- 不更换网站整体信息架构、字体体系、域名或表单服务。
- 不增加第三方 Logo 外链、联盟推广或滚动品牌跑马灯。
- 不生成或冒充 Shawnnova 本人的清晰肖像。
