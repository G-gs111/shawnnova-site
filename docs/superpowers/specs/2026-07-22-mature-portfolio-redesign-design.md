# 葛少玉（Shawnnova）成熟版个人站设计规格

日期：2026-07-22

## 目标与受众

将现有个人站从“学生作品展示”升级为面向招聘方与潜在合作方的成熟个人主页。核心定位采用用户选择的 **1A：业务型产品构建者**，主要求职方向为 AI 产品、产品运营与业务数字化，同时保留个人站和轻量 Web 产品合作入口。

教育信息采用用户选择的 **2C：弱化学生身份**：不进入首屏或核心能力区，仅在经历末尾以简历事实作简洁证明，避免把整站写成校园简历。

上线采用用户选择的 **3A**：保留现有留言能力，先完成检查版本，再直接更新正式域名 `https://260604.xyz`。

## 核心叙事

- 角色：业务型产品构建者
- 主标题：从业务现场，到可用产品。
- 价值表达：把运营、销售、产品和 AI Web 开发连成一条交付链，从识别真实问题到完成可使用的产品。
- 个人信条：功不唐捐，玉汝于成。
- 语气：克制、具体、以结果和交付为主，不使用空泛的“热爱”“赋能”等套话。

## 页面结构

1. **固定导航**：显示葛少玉 / Shawnnova，当前区块使用黑色圆角标签指示；移动端保留品牌和联系入口。
2. **首屏**：超大中英文字排版；黑色圆形遮罩跟随鼠标，揭示反色文案与身份信息。触屏端居中展示，减少运动模式下停用追随动画。
3. **结果证据**：以四个数据卡呈现跨业务、运营和执行能力：专业排名 1/67、服务 100+ 家长、社群/公众号 6000+ 关注、双 11 营业额增长 200%+。所有数字均来自简历，不补造数据。
4. **代表项目**：
   - 宠物达人内容运营工作台：已正式上线并投入某宠物内容电商机构达人团队使用；展示脚本改写、合规预检、对标素材和知识学习能力。
   - 个人站开发：已上线；呈现从内容结构、交互设计、开发到域名部署的完整交付。
   - AI 混剪工具：开发中；明确标注状态，不包装为已上线。
   - 企业自动化工作流：探索中；描述连接表单、数据、消息和协作工具的目标。
5. **经历路径**：按“业务运营 → 产品交付 → 组织协作”的逻辑压缩淘宝店铺运营、物流运营、家教平台和校园组织经历；奖项和教育作为末尾补充证明。
6. **合作方向**：AI 产品/产品运营岗位、个人站与轻量 Web 产品、内容运营工具与业务工作流三类入口。
7. **联系**：保留邮箱、手机号、GitHub 与访客留言表单；表单仍投递到已配置的 QQ 邮箱服务。

## 项目匿名与真实性

- “色彩萌宠”不是达人名称，也不在个人站公开展示。
- 对外统一称为“某宠物内容电商机构”或“宠物达人内容运营工作台”。
- 不展示公司名称、Logo、达人账号、后台数据或敏感配置。
- 不使用无法验证的用户数、效率提升或转化率；项目状态分别写清“已上线”“开发中”“探索中”。

## 视觉与交互方向

参考 `https://www.lius-node.com/#about` 的界面语言，但不复制品牌内容或素材：

- 近白背景、黑色文字、极少量钴蓝强调色，大面积留白与细线分区。
- 超大标题、编号项目卡、圆角标签、轻微网点/网格纹理。
- 首屏圆形遮罩跟随鼠标；导航随滚动更新当前区块；数字卡进入视口时轻量显现。
- 卡片使用真实文本和 CSS 结构，不依赖通用库存图，避免“模板站”观感。
- 动画必须尊重 `prefers-reduced-motion`，键盘焦点清晰。

## 响应式与可访问性

- 重点检查 1440px 桌面和 390px 手机视口。
- 手机端不得横向溢出；项目、数据和联系区改单列。
- 每个页面区块拥有语义化标题与锚点；导航和表单支持键盘操作。
- 首屏交互是增强效果，关闭 JavaScript 或减少动画时内容仍清晰可读。

## 验收标准

- 首屏在 5 秒内说明“我是谁、能做什么、正在找什么”。
- 项目名称、状态和匿名规则准确，不再把“色彩萌宠”写成达人。
- 简历经历经过成熟化重写，教育信息按 2C 弱化，不学生化。
- 复现参考站最具辨识度的圆形遮罩、活动导航和大字号留白节奏，但保持 Shawnnova 自有内容。
- 桌面与手机 Chrome 中布局、导航、链接、表单、焦点和减少动画模式均可用。
- 单元测试、代码检查和生产构建通过；正式域名更新后再在 Chrome 中复核。

## 非目标

- 本轮不增加登录、支付、数据库、博客后台或中英文切换。
- 本轮不公开公司内部截图和敏感经营数据。
- 本轮不为尚未上线的项目虚构链接、客户或效果数据。
